# Tally

A personal budget PWA. Income, expenses, category limits, recurring bills, and savings goals. Data stays in this browser (IndexedDB). Export a JSON backup from Settings.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

```bash
npm test
npm run build
npm run preview
```

## Install on a phone

- **Android Chrome:** browser menu → Install app, or the button in Settings.
- **iPhone:** Safari → Share → Add to Home Screen.

Use the same browser you installed from. Clearing site data deletes the budget unless you exported a backup.
